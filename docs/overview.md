# 项目概览

本项目整理 Zeus S2 移动小车从激光 SLAM、传统导航，到 PPO 强化学习局部避障及 ROS1 插件接入的工作。资料主线是：在 Isaac Lab 中训练策略，导出带观测归一化的 ONNX 模型，在真实小车上构建激光和目标观测、调用策略并发布控制命令，再用统一记录器保存轨迹、模型输入和任务状态。

仓库保留开发过程中不同阶段的代码、模型与实验记录。它是一份可追溯的项目归档；保存的 C++ 插件尚无完整编译和实车验证证据，各历史分支不能直接视为同一套可复现发行版本。具体边界见[验证状态](limitations-and-validation.md)。

|---|---|---|
| 激光观测处理 | 车头方向对齐、异常测距修复、181束重采样、三帧堆叠、修复mask及时间戳跟踪 | [Python节点包](../ros1/python_nodes/rl_planner/) |
| 策略部署 | 556维观测拼接、归一化与actor导出、ONNX推理、动作映射及限幅 | [模型与导出](../models_and_export/) |
| 真实导航与评价 | RL/DWA/遥控切换、目标生命周期、轨迹和obs记录、实车8次trial、仿真对照 | [实验目录](../experiments/) |
| 全局路径接入 | 从全局路径选择局部目标、C++ `nav_core::BaseLocalPlanner` 封装 | [插件包](../ros1/local_planner_plugin/rl_planner/) |
| 训练配置保存 | Stage1 PPO环境与agent配置、差速动作、目标生成 | [训练快照](../training/stage1/) |
| 研究整理 | 激光时序、奖励塑造、DWA/RL融合、评测基准与历史设计讨论 | [论文阅读](../literature/README.md)、[研究笔记](research_discussions/README.md) |

## 实验概况

已保存四份各900回合的仿真 episode CSV，按 `outcome` 字段、无过滤重新计数如下。两份DWA来自不同设置，分别展示。

| 文件对应方法 | 成功 | 碰撞 | 超时 | 成功率 |
|---|---:|---:|---:|---:|
| ESA_ON | 814 | 73 | 13 | 90.44% |
| ESA_OFF | 266 | 591 | 43 | 29.56% |
| DWA原版 | 124 | 229 | 547 | 13.78% |
| 0414对标ESA设置的DWA | 189 | 344 | 367 | 21.00% |

这些结果对应仓库保存的数据文件。CSV的场景、速度档位和起始距离可以按episode对齐，但完整仿真配置、模型对应关系与其他约束仍需继续核对，不能把文件标签直接当成公平对照的完整证明。

实车还保存RL 39份、DWA 36份summary。记录器的 `success=1` 主要表示到达状态；部分目录名含碰撞标记，不能据此报告100%无碰撞成功率。毕业论文初稿中的比例与900回合CSV不同，已在[验证边界](limitations-and-validation.md)分别记录，避免混用口径。
