## 插件展开目录与压缩包差异

当前展开的两个插件快照保留在[主插件](../ros1/local_planner_plugin/rl_planner/)与[fixed归档](../archive/plugin_fixed/)。模型主图相同，C++源码有实质差异，不能把fixed名称当成可靠的新旧标志。

原 `rl_planner.zip` 还包含四份独有历史文本：CMakeLists、参数YAML、头文件和C++实现。该压缩版的位置到达阈值0.5m、最大线速0.5m/s；虽读取yaw_goal_tolerance，但对应目标接口没有据此判断终点朝向。它每轮变换全路径、从最近路径点起按欧氏距离挑选前瞻点。

展开版本已出现0.1m/0.1rad容差、0.3m/s最大线速、路径裁剪索引、线段投影和终点yaw处理等修改。这些实现差异不能推导出哪一版已在实车运行。历史文本应与其来源和哈希配套保存。

## 统一使用前需要确定的配对

| 对象 | 不同取值或实现 |
|---|---|
| 模型 | 194 / 556维；opset13 / 17 / 18；内嵌 / 外置权重 |
| 激光尺度 | 早期说明及部署尺度16米，后修正为训练对应的12米；8米为早期讨论建议而非最终主线 |
| 目标来源 | RViz最终目标、路径前瞻点、终点yaw误差 |
| 前瞻距离 | 讨论1.5m、旧归档0.6m、插件0.8m、其他launch1m等 |
| 动作 | raw物理v/w后限幅，或clip[-1,1]再映射 |
| 速度范围 | 源码默认、launch覆盖、YAML和当次运行参数不同 |
| 激光滤波 | Python主要针对修复beam，C++中位处理范围不同 |

[历史研究笔记](research_discussions/README.md)记录了各讨论的最终约束与撤回建议。
