# 模型与导出资料

| 目录 | 内容 |
|---|---|
| RL | opset13内嵌权重的556维model_1200_actor；opset17的194维zeus_stage1_model_1999；两个导出脚本 |

两类model_1200_actor同名但不是同一导出文件；不能仅按文件名互换。556维网络拓扑为556→512→256→128→2，ELU，导出包含训练mean/std归一化。194维模型属于另一阶段。

观测主线为13维本体/目标状态和181×3维激光，共556维；保留dz=0占位。当前观测函数默认max_distance=12m。早期接口文字写过16m，后续终端配置与代码使用12m，请保留历史纠正，按具体模型匹配预处理。

所有PT仅按文件字节归档，未在整理过程中反序列化；本次没有推理或训练验证。导出脚本保留历史绝对路径，需在原训练环境设置路径与依赖后使用。同内容PT副本已去重，RL-onnx下原model_1200.pt与 `最新模型及观测要求/model_1200.pt` 相同，以后者为准。

截图关于动作解释需要与训练阶段对应：Stage1保存代码直接将raw值当v/w限幅，而部署代码有归一化动作线性映射；未找到Stage3完整动作实现的对应本地文件，不能默认两者完全等价。
