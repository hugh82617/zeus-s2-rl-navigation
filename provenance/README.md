# 来源与整理方法

`source-files.csv`记录复制来源的相对路径、目标路径、源文件字节数和SHA256。它用于资料追溯；仓库新增说明、分析JSON中的可移植路径及Git的文本换行规范可能与原文件不同。视频的逐文件来源、别名、时长与SHA256见 `media/catalog.csv` 和 `media/catalog.json`。

代码按Python部署、C++插件、历史分支整理；模型保留配套权重；实验批次分开保存。第三方论文以书目和阅读笔记引用；安装包、学校行政表格、重复压缩包、构建缓存、逐帧图片序列和大型bag未上传。相关视频按SHA256去除完全重复路径，其余保留原片与各剪辑版本，通过Release分类提供。

原始知识库保持原样。这里没有用文件修改时间认定代码已验证，也没有把聊天建议当作已取得的实验结果。整理日期：2026-11-15。
